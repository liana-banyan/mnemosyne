MnemosyneC 0.9.40: what is new

Relay traffic is now end to end encrypted per peer. A message relayed between two of your machines is sealed for that one recipient with the two machines' own relay keys (X25519, with a fresh message key and nonce every time, AES-256-GCM), so the relay in the middle carries only ciphertext it cannot read. The old relay format, which anyone holding the public key could open, is no longer sent or accepted by default. Each machine also proves it owns its own presence and relay rows with a secret kept in Windows encrypted storage, and never sent anywhere but the Liana Banyan server functions that check it.

Enrollment screen, Founder only. Settings now carry "Enroll the Founder's machines", labelled: Founder only: enroll the Founder's machines. Member enrollment is coming. It is checked only against the Founder's authenticator code on the Liana Banyan server; for anyone else it shows that label and nothing happens. After five wrong codes it locks for 15 minutes, doubling each time, and says so plainly.

A near match is now a suggestion, never the answer. When your question is only similar to one answered before, the app answers yours and shows the earlier one beside it: "A similar question was answered before", with a button to open it. An exact match still comes straight from the record.

Share buttons. Settings, Share cards with other machines: share one of your own cards with a machine you have saved, and accept or refuse cards offered to you, with the signed receipt shown in plain words.

The updater installs only forward. It installs only the highest version it finds, only when it is newer than the one you are running, runs each installer at most once, and moves any older staged installer into a quarantine folder instead of running it. Known issue in 0.9.39 and earlier: when automatic updates were set to install on quit, the updater could run an older installer still sitting in the updates folder (on 2026-09-27 a chain of stale 0.9.38, 0.9.37 and 0.9.36 installers ran one after another). Workaround for 0.9.39 and earlier: remove any *.exe.ready file older than your installed version from %USERPROFILE%\.mnemosynec\updates before quitting the app.

One authenticator seed. The second local seed paths are retired: nothing in the app can ask for or use a second authenticator seed, and the local code checker is removed. The only verifier is the server side one.

Cards can now say they were answered by your own AI (Ollama) through the Conduit.

Known and open: relayed dispatch between two machines works only when both run 0.9.40 and are enrolled with each other; an older build and 0.9.40 do not talk over the relay. The share and the enrollment screens have been tested in code and on one machine; the two machine run is next. On first launch after install the app may close once by itself after a few seconds; open it again and it stays running.
