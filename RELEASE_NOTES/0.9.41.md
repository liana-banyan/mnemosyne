# MnemosyneC 0.9.41

Removes the old screen overlay, which caused mouse stutter on some machines.

- The full-screen, always-on-top overlay window is gone, and so is the mouse pass-through that sent every mouse movement to the app.
- The "Show Overlay" and "Hide Overlay" tray items are removed. Nothing pops up after install any more.
- Everything else is unchanged from 0.9.40.
