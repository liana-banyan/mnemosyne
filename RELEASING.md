# MnemosyneC Release Process

## Overview

MnemosyneC uses `electron-builder` to produce Windows installers and publishes them to
`liana-banyan/mnemosynec-releases` on GitHub. The auto-updater feed (`latest.yml`) is
served from `https://mnemosynec.ai/download/latest.yml`, which is a **static file** in the
Cephas Hugo site (`Cephas/cephas-hugo/static/download/latest.yml` in the LianaBanyanPlatform
workspace). It is NOT auto-updated by electron-builder publish; it must be manually updated
on every release.

## Pre-flight

- [ ] Bump `version` in `package.json`
- [ ] Verify `caithedral-core` dependency is pinned to the correct version
- [ ] Run `npm run build` locally and confirm no TypeScript errors
- [ ] Confirm `npm run dist:win` produces `release/latest.yml` with correct sha512/size

## Build

```powershell
# From the mnemosyne source directory:
npm run publish:win
```

Artifacts land in `release/`:
- `MnemosyneC-Setup-<version>.exe` (NSIS installer)
- `Mnemosyne-Portable-<version>.exe`
- `MnemosyneC-Setup-<version>.exe.blockmap`
- `latest.yml` (electron-builder generated -- contains verified sha512/size)

## Publish to GitHub Releases

Upload `MnemosyneC-Setup-<version>.exe` and `Mnemosyne-Portable-<version>.exe` to
`liana-banyan/mnemosynec-releases` as a new release tagged `v<version>`.

```powershell
gh release create "v<version>" \
  "release/MnemosyneC-Setup-<version>.exe" \
  "release/Mnemosyne-Portable-<version>.exe" \
  --repo liana-banyan/mnemosynec-releases \
  --title "MnemosyneC v<version>" \
  --notes "<release notes>"
```

## CRITICAL: Update the Auto-Updater Feed

**This step is the most commonly missed. Without it, all installed copies stay frozen on the
last version where latest.yml was updated.**

Open `Cephas/cephas-hugo/static/download/latest.yml` in the LianaBanyanPlatform workspace
and update it from the electron-builder generated `release/latest.yml`. The `url` field
MUST be the absolute GitHub releases download URL (not a relative path) because the installer
is hosted on GitHub, not on mnemosynec.ai.

Template:
```yaml
version: <version>
files:
  - url: https://github.com/liana-banyan/mnemosynec-releases/releases/download/v<version>/MnemosyneC-Setup-<version>.exe
    sha512: <value from release/latest.yml>
    size: <value from release/latest.yml>
path: MnemosyneC-Setup-<version>.exe
sha512: <value from release/latest.yml>
releaseDate: '<value from release/latest.yml>'
```

**Source of truth for sha512/size:** `release/latest.yml` generated by `electron-builder`.
NEVER hand-compute these values; use what electron-builder generated.

## Deploy Cephas

```powershell
cd C:\Users\Administrator\Documents\LianaBanyanPlatform\Cephas\cephas-hugo
hugo --minify
firebase deploy
```

## Verify

```powershell
# Should return the new version:
curl https://mnemosynec.ai/download/latest.yml
```

## Checklist Summary

- [ ] Bump `version` in `package.json`
- [ ] Run `npm run publish:win` (generates `release/latest.yml` with verified sha512/size)
- [ ] Create GitHub release on `liana-banyan/mnemosynec-releases` with installer assets
- [ ] **Update `Cephas/cephas-hugo/static/download/latest.yml` with new version metadata**
- [ ] Run `hugo --minify` in `Cephas/cephas-hugo`
- [ ] Run `firebase deploy` (Cephas target)
- [ ] Verify `https://mnemosynec.ai/download/latest.yml` returns the new version

## Root Cause Note (2026-06-09, SEG-Q-15)

Prior to this fix, `latest.yml` was frozen at `v0.1.9` (committed 2026-05-23) while
releases v0.1.10 through v0.1.32 shipped to GitHub without the feed being updated.
Every installed copy reported "Update for version X is not available (latest: 0.1.9)".
Fixed by updating to v0.1.32 and documenting this mandatory step in the release checklist.
